Arabic translation review

Each numbered JavaScript file contains the Arabic text for the corresponding presentation slide. These files are already connected to the presentation, including text used in scenes, captions, buttons and navigation.

How to make changes

  1. Make a copy of the content/ar/ folder before editing.
  2. Open the relevant .js file in a plain-text editor. Edit only the quoted text values on the right of each colon. Keep the field names on the left, commas, brackets and quotation marks unchanged.
  3. Save the file using UTF-8 encoding. If a sentence needs a double quotation mark, write \" inside the text. Do not use a word processor to save the JS files.
  4. Return the edited files. Replace the files with the same names in the presentation's content/ar/ folder.
  5. Reopen index.html, switch to Arabic, and review the affected slides. If already open, refresh the page. No build or installation is required.

Slide titles, captions, 3D labels and controls may have separate entries where they appear in different views. Review all entries in each file. Shared wording used by several scenes and the presentation controls is in 00-shared.js. Do not translate field names, change array structure, or rename files. Keep product names and technical abbreviations where appropriate.

Where not to edit

Leave the existing top-level content/ar.js, the other content files and the scripts/ folder unchanged. They retain the approved text as a fallback and read your changes from this folder. Only the numbered JS files in content/ar/ need to be returned.
